# Presupuesto de Camila Conde

Sitio en React + Tailwind para revisar opciones de alojamiento de intercambio en A Coruña.

## Stack

- React 19
- Vite 8
- Tailwind CSS 4
- React Leaflet
- GitHub Pages con GitHub Actions

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

El `base` de Vite se calcula automaticamente para GitHub Pages usando `GITHUB_REPOSITORY`, asi que el mismo proyecto funciona como sitio de usuario o como Pages de proyecto.
